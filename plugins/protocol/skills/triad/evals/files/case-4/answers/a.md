Check first whether the sync is copying everything again instead of only
the changed files. A jump from 20 minutes to 4 hours fits a full copy
much better than a slow disk. Look at last night's sync log and compare
the number of files transferred with a log from two weeks ago. If nearly
every file was transferred, something changed the file dates or the
permissions on one side, often a restore or an antivirus scan. Fix that
and the next run after it should be short again.
